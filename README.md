# AutoOps-Insight

**Converting CI/CD failures and customer health signals into escalation-ready operational intelligence.**

`Python` · `FastAPI` · `React` · `Scikit-learn` · `Prometheus`

---

## Why This Exists

**Problem:** CI/CD failures produce noisy, unstructured logs. Operations teams triage instead of resolve. Customer health degrades silently — escalation growth goes undetected until it becomes an executive problem.

**Impact:** Engineers spend time on symptom-level debugging. Customers at risk aren't identified until the pattern is already severe.

**Proof:** ML classifier (TF-IDF + LogisticRegression) turns raw build logs into structured failure classes. Customer health aggregation surfaces at-risk accounts and escalation trends before they require reactive response.

## Why AutoOps-Insight

CI/CD failures produce noisy logs with no structure. Operations teams spend time triaging instead of resolving. Customer health degrades silently until it becomes an escalation.

AutoOps-Insight turns raw build logs into structured intelligence:

```
Upload CI/CD log
      │
      ▼
ML classifier (TF-IDF + LogisticRegression)
  → predicted failure class + confidence
      │
      ▼
Customer health aggregation
  → at-risk count · escalation trend · severity distribution
      │
      ▼
Executive summary
  → REQUIRED / MONITOR / HEALTHY
```

---

## Architecture

```
AutoOps-Insight/
  Log ingestion       FastAPI endpoint · .txt log upload
  ML pipeline         TF-IDF vectorizer · LogisticRegression classifier
  Health scoring      Customer-level aggregation · trend detection
  Executive layer     Escalation routing · summary generation
  Observability       Prometheus /metrics endpoint
  Frontend            React (Vite) + Tailwind CSS dashboard
```

## Run Locally

```bash
git clone https://github.com/kritibehl/AutoOps-Insight && cd AutoOps-Insight

# Backend
cd backend && pip install -r requirements.txt
uvicorn main:app --reload

# Frontend
cd frontend && npm install && npm run dev
```
