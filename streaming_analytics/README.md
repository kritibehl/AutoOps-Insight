# Streaming and Batch Analytics for Operational Telemetry

This module models data-engineering workflows for AutoOps monitoring data.

## Includes

- Kafka-style telemetry ingestion
- Spark-style batch aggregation
- anomaly summaries
- SQL warehouse schema
- dimensional modeling notes
- monitoring reports

## Outputs

- `kafka_event_summary.json`
- `batch_metrics_summary.json`
- `stream_window_metrics.json`
- `anomaly_detection_report.md`

## Resume signal

Real-time ingestion, batch ETL, SQL warehouse modeling, anomaly detection, and monitoring analytics.
