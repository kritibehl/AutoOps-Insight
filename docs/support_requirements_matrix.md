# Support Requirements Matrix

| Requirement | AutoOps Workflow | Evidence |
|---|---|---|
| incident triage | support ingestion + lifecycle tracking | SLA and escalation reports |
| escalation workflows | role-aware escalation controls | RBAC artifacts |
| release-risk attribution | deployment-to-incident correlation | rollback risk summaries |
| partner-impact review | integration issue review | workflow case study |
| operational analytics | incident search and dashboards | service-owner APIs |
| support documentation | runbooks and escalation docs | operational docs |
| API evidence review | release-correlation + RCA APIs | live Cloud Run APIs |
| reporting workflows | SQL exports and summaries | CSV/JSON reports |
| RCA generation | incident RCA generator | postmortem artifacts |

## Supported operational workflows

- partner support
- integration troubleshooting
- escalation management
- release review
- operational analytics
- support documentation
- service-health review
