# ML Monitoring Workflows

AutoOps includes ML monitoring workflows for operational model-health review.

## Includes

- feature drift detection
- prediction-quality regression tracking
- latency regression checks
- anomaly pattern summaries
- dashboard-ready model-health metrics

## Artifacts

- `anomaly_detection_pipeline.py`
- `feature_drift_report.md`
- `prediction_quality_metrics.json`
- `model_health_dashboard.json`

## Operational use

This module supports ML monitoring and data-platform support workflows by turning model evaluation signals into dashboard-ready health metrics and recommended review actions.
